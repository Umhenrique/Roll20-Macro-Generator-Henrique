# Roll20 Macro Generator (Enhanced Fork)

This is a fork of the Roll20 Macro Generator.

## Updates

### 1. **Macro Preview & Output Enhancements**
- **Attack Type** and **Damage Type** are now added.
- Image/gif output uses the correct Roll20 syntax for in-chat display.

### 2. **UI/UX changes**
- Placeholders for damage and critical fields.
- All form labels, tooltips, and buttons update with the selected language.
- Macro preview updates in real time as you edit fields.

### 3. **General QoF**
- Save, load, and delete macros with persistent storage.

## 🛠️ How to Use
1. Fill out the macro form with your attack details.
2. The macro preview updates live as you type.
3. Save, load, or delete macros as needed.
4. Copy the generated macro to use in Roll20 chat.

## ⚠️ Notes
- The default Roll20 template does not support advanced formatting (like centering titles), but this fork makes the output as clear and attractive as possible within those limits.
- For more advanced formatting, consider using a Roll20 character sheet with custom templates.
